# How to Contribute

## First and foremost

Read and understand the [AI Policy](AI_POLICY.md) and the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting bugs

> [!IMPORTANT]
>
> If it is a security vulnerability, **do not** open a public issue. Open a security report using the Security tab.

- Ensure the bug was **not already reported** by searching on GitHub under Issues. Using _keywords_ can help you better find existing issues.
- Include clear **title**, **description**, **expected behaviour** and **reproduction steps** (e.g. which commands should be executed).
- If appropriate and relevant, include the **full console output** as well as **system information** whenever possible.

## Contributing code

- Disclose whether you have used AI.

  - Appropriately add `Assisted-by` trailer with the name of the agent and (if applicable) the model used.

  - If possible, don't use the `Co-authored-by` trailer or any other similar trailers.

  - Do not allow your agent to create pull requests or write descriptions, walkthrough etc. for you. Write descriptions by hand.

- Your contribution **will be reviewed by an AI solution**, called [CodeRabbit](https://www.coderabbit.ai/). This will generate an overview, a walkthrough and find potential defects and detect slop.

- Write clear **title and description** for the pull request, conforming to the template if one is available.
