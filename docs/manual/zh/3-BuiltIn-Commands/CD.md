# CD

| 来自 | 信息           |
|----|--------------|
| 模块 | IceShell 核心  |
| 版本 | v0.1.0-alpha |

更改当前所在的工作目录。如果未指定欲更改为的目录，则显示当前工作目录。

```bat
cd [directory]
```

### 参数

- **directory**：_选填_。欲更改为的工作目录。

### 返回代码

任何情况下都返回零，且不报错。
