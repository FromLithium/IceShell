# 1. 词语定义

- _提升权限_：在 Windows 上指以管理员权限运行；而在 *nix 系统中则是以 `root` 运行。
- _可执行文件_：一个可被作为程序执行的文件。在 Windows 上一般是 `EXE` 文件（PE 格式），而在 Linux 上是 ELF 格式。
- _外部命令_：一个使用命令行界面的外部程序。这种程序因其在 IceShell 内可以作为命令而执行，故称外部命令。
- _内部命令_：IceShell 的内置命令，或者模块向 IceShell 附加的命令。

## 命令示例

- 以半角尖括号包围的参数（如 `<argument>`）是*必填参数*。
- 以半角方括号包围的参数（如 `[argument]`）是*选填参数*。
- 未被任何括号包围的任何字词须直接按原位置写上。
