# 3. Built-in Commands

This section describes the built-in commands of the IceShell shell interpreter, and commands in the modules that comes default with the IceShell standalone interpreter program.

To enable them in your own launcher or host application, you will have to associate it with the shell dispatcher by using the `IceShell.Core.Commands.Bundled.DefaultCommands` utility class.
