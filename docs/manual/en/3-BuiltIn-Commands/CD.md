# CD

| Name   | Description   |
|--------|---------------|
| Module | IceShell Core |
| Since  | v0.1.0-alpha  |

Displays or changes the current working directory.

```bat
cd [directory]
```

### Arguments

- **directory**: _Optional_. The directory to change to. If not specified, displays the current working directory.

### Exit Code

Always return 0 with no error.
