# 5.2. Modules

Modules are types that implements `IModule`. They can be added to module 
managers and be initialised there. Upon initialisation, modules add
commands and do other code to add their functionality to IceShell.

For security reasons, module manager can only initialise once. Any further
attempts to initialise the module manager, or add any new modules to module
manager after its initialisation will result in exception.

## Adding new modules

The process of adding new modules should only be done once for Interactive
shell runs - that is, before the Interactive shell start. The Interactive shell
will initialise the module manager at its startup.

For non-Interactive shells (that only runs commands), the launcher must
initialise the module manager before running any module commands.

You can search for modules within a folder by calling `LoadDirectory` on a 
module manager, but beware, it is _not_ compatible with NativeAOT.

## Security

Please note that _all modules are full-fledged_ computer programs that can
execute just about any code on your computer. You should not run any module
that you don't trust.

Exercise all cautions on modules just like that you would exercise on computer
programs.
