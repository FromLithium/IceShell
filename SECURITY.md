# Security Policy

## Important considerations

IceShell does not enforce a security boundary on its own.

Misconfiguration of your environment can blow a hole its security boundary to allow IceShell to be used to circumvent the boundary. That is not an issue with IceShell.

Never allow untrusted input to ever flow into shell commands. **Never**.

## Reporting a security issue

Report any security issues by using **the security tab** on the GitHub repository, and nowhere else.
